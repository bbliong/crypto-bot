# Profit4 paper monitor

`npm run dashboard:profit4` membuka dashboard di http://127.0.0.1:4178 (port dapat diubah lewat `PROFIT4_DASHBOARD_PORT`). Start/Restart menjalankan `scripts/run-profit4-watch.mjs`; CLI juga tersedia lewat `npm run wallet:profit4-watch`. Gunakan satu worker pada satu waktu. Chrome terlihat, memakai profil login yang tersedia. Worker distribusi lama harus berhenti karena profilnya sama.

Dashboard memakai empat tab seperti Research: Ringkasan, Posisi Aktif, Riwayat Transaksi, dan On-Chain & Auto-Buy. Pilihan Semua sesi / Live / arsip per run berlaku pada statistik, lane, breakdown jam, posisi, transaksi, quote, rules tersimpan, dan event. Sesi bawaan adalah Live jika tersedia, selain itu Semua sesi. Riwayat memiliki pencarian, filter lane/jam/status, sorting, dan pagination 25 baris. Posisi `CENSORED` tetap memiliki hasil belum diketahui dan tidak masuk PnL selesai atau win/loss. Rules arsip yang tidak tersimpan ditampilkan sebagai tidak tersedia.

Tab On-Chain berisi kontrol worker, wallet pantauan, quote paper BUY/SELL, konfigurasi Real Auto-Buy, posisi real, serta audit transaksi. Kontrol dashboard tidak memakai password. Siapa pun yang dapat membuka domain bisa melihat audit, mengubah konfigurasi, dan menyalakan Real Auto-Buy. Kontrol worker dan daftar wallet selalu menunjukkan konfigurasi saat ini. Edit wallet dan filter dipertahankan saat refresh. Navigasi tab tersedia di atas pada desktop dan di bawah pada mobile; tab aktif disimpan khusus untuk Profit4.

Rules satu putaran mengikuti kandidat cap4: observasi30s, minimal30s setelah transfer, monitor terlambat maksimal15s, batas entry180s dari quote pertama, buy-share5s>=50%, buy bermakna5s>=USD5, >=1buyer, holder count/growth15s fresh dan tidak turun, momentum0.3–5%, drawdown<=5%, rise<=15%, tanpa sell>=USD250. Entry diperiksa lagi pada quote setelah latency>=1s. Target4% bersih dihitung via policy cap4, stop5% bersih, hold300s; tidak ada trailing atau exit flow tambahan.

ModalUSD5, model biaya1%/sisi, slippage0.5%/sisi, biaya tetapUSD0.005/sisi. PnL adalah paper berbasis harga socket, bukan swap route atau fill nyata. Stop tidak menjamin loss maksimal5%. Putaran kedua tidak dijalankan. Ledger `bought-mints.json` mencegah entry ulang pada mint yang pernah dibeli, termasuk sesudah restart.

Wallet default diambil dari daftar dashboard distribusi saat pembuatan konfigurasi Profit4. Edit/tambah/hapus lewat satu tabel; Simpan & restart menerapkan perubahan dan memberi peringatan posisi terbuka menjadi exit kurang data. Satu controller mengecek satu wallet setiap minimal 5 detik secara bergantian (`--walletPollMilliseconds 5000`). Setiap wallet menggunakan dua request, transfer-in dan sell, dengan jeda500ms antar-request (`--pollMilliseconds 500`). Untuk tiga wallet, setiap wallet dicek sekitar setiap15detik dan polling aktivitas maksimal24request/menit; request dari halaman detail GMGN terpisah. Latensi yang panjang dan backoff429 dapat memperlambat putaran. Maksimal satu detail per wallet. Detail tetap merekam setelah paper sell, sampai wallet asal sell, diganti transfer baru, atau worker berhenti.

Log API, raw socket, transaksi token dan event paper berada di `data/profit4-watch/<run>/chunks/<WIB-window>/`, partisi30menit. Snapshot per sesi `profit4-state.json`; kontrol/PID di `worker-control.json`; log proses `worker.log`. Respons HTML/non-JSON disimpan dan polling ditandai gagal. HTTP429 memakai waktu tunggu tetap15detik sebelum mencoba wallet berikutnya, termasuk saat error berulang; socket tetap direkam. Dashboard memisahkan PnL selesai, estimasi posisi terbuka, dan exit kurang. Hasil paper historis lama ditampilkan terpisah.

Real Auto-Buy memakai sesi GMGN pada profil Chrome worker yang sama, tanpa menyimpan private key. Wallet eksekusi dideteksi otomatis dari request GMGN atau audit sesi Research terbaru, dengan fallback wallet yang sama seperti dashboard Research; tidak perlu memilih alamat manual. Sesi otorisasi dibaca dari request GMGN atau token JWT pada storage browser. Saldo SOL dibaca langsung dari RPC dan tetap ditampilkan meskipun sesi trading GMGN belum siap. Dashboard mengambil saldo secara mandiri dengan cache 15 detik; kegagalan pembacaan ditampilkan sebagai error, bukan saldo nol. Harga SOL diambil pada server agar tidak tergantung CORS browser. `SOLANA_RPC_URL` dapat memakai endpoint RPC pilihan. Login GMGN, saldo, harga SOL dan lane aktif harus tersedia untuk mengaktifkan BUY.

Konfigurasi default: lane V4, stake USD0.5 (alternatif SOL0.003), kuota3 BUY terkonfirmasi, maksimal1 posisi aktif, slippage BUY9%/SELL14%, priority/tip masing-masing0.0001SOL, reserve0.025SOL, Anti-MEV OFF, Auto-Sell ON. Lane yang tersedia mengikuti worker: Bounce V1–V4 atau P4. Kuota0 berarti tidak terbatas. Konfigurasi disimpan terpisah di `autobuy-settings.json`; setiap startup/restart mematikan BUY baru. OFF tetap memungkinkan penyelesaian order pending dan Auto-Sell posisi bot. Reset kuota tidak menghapus audit atau posisi.

BUY mengikuti sinyal PAPER_BUY dari lane terpilih, setelah pemeriksaan saldo, kepemilikan token, reserve, kuota dan kapasitas. Sinyal exit lane asal memicu SELL; setiap posisi juga mempertahankan monitor tersendiri agar penggantian tab pantauan tidak menghentikan pemantauan. SELL manual menjual 100% sisa token yang dimiliki posisi bot. Worker tidak dapat dihentikan atau di-restart dari dashboard ketika ada posisi real aktif.

Ledger `real-trade-ledger.jsonl` dan snapshot `real-state.json` berada langsung di `data/profit4-watch/`. Audit mencatat sinyal, quote, submit, order ID, signature, konfirmasi, kegagalan dan hasil aktual. Order belum dianggap berhasil sampai transaksi terkonfirmasi on-chain. Kuantitas berasal dari perubahan saldo token wallet; cashflow mencakup SOL native dan wrapped SOL. PnL selesai hanya tersedia bila semua cashflow dapat direkonsiliasi. Order timeout/UNKNOWN tidak dikirim ulang otomatis. Jika signature belum terdeteksi dari respons GMGN, buka Detail audit dan masukkan signature untuk pemeriksaan RPC; tindakan ini tidak mengirim order baru.

Dashboard tidak memerlukan password admin. Akses ke domain memberi kendali atas worker, audit, dan Auto-Buy. Token sesi GMGN serta payload transaksi bertanda tangan tidak dimasukkan ke audit real.

Domain: https://cr.bbliong.io/profit4. Layanan user systemd `crypto-bot-profit4-dashboard.service`; worker saat ini `crypto-bot-bounce-worker.service`. Pengujian otomatis menggunakan adapter/mock; worker dihentikan setelah deployment; pemilik dapat memulainya dari dashboard. Real Auto-Buy tetap OFF hingga diaktifkan melalui dashboard. Rules masih eksperimental; perubahan biaya aktual dan latency dapat mengubah hasil.
