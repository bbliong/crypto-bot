## Mekanisme kode yang menjelaskan hasil
- Entry AP2: umur sejak whaleFirstBuyAt >=60s, bundler >=5%, remaining/peak >=40%, whaleBuysCount>=1. Whale aktif memakai jumlah buy kumulatif, tanpa batas freshness aktivitas. Ini bukan jaminan anti-rugpull 100%, dan bukan filter historis seluruh pola distribusi.
- Exit whale AP2: giant >=15 SOL atau >=$1.300, atau tiga significant sells; significant >=3 SOL/>=$250 atau remaining <50% peak. Buyback mereset consecutive sells. Order kecil berkala dapat lolos gate ini.
- Exit harga AP2 menunggu TP1 +50%, TP2 +100%, SL -20% berdasarkan tick harga yang diterima; tidak ada profit lock khusus di +10%/+15% untuk AP2. Tick meloncat tidak dapat menjamin exit tepat pada ambang.
- Dev watcher mengabaikan kategori withdraw/close/claim demi discovery pool baru; tidak meneruskan event mint-linked sebagai emergency exit AP2. Jangan mengubahnya menjadi unconditional sell untuk semua generic hint, karena fee claim dapat ikut terklasifikasi.
- Helper autoRotateSameSymbolPositions tidak dipanggil untuk AP2 pada jalur S14: perpindahan target ke CA baru tidak otomatis menyelesaikan posisi AP2 lama.
- checkStagnantPositions memakai umur sejak openedAt, bukan umur sejak aktivitas whale terakhir. Ia menghapus posisi dan menulis totalReturnedUsd=0 / roi=-100 tanpa onTradeAction SELL/quote.
